# Email signature – Daniel Rod, Chamberlains

- `signature.html` – HTML signature (open https://dannysrod.github.io/email-signature/signature.html, select all, copy, paste into your mail app's signature settings)
- `images/` – images used by the HTML, served via jsDelivr:
  `https://cdn.jsdelivr.net/gh/dannysrod/email-signature@main/images/<file>.png`
- `png/` – the whole signature as a single image (4x, 2x, 1x)

To update an image, replace it here under the same name and push, then open
`https://purge.jsdelivr.net/gh/dannysrod/email-signature@main/images/<file>.png` to refresh the CDN.
